# Heracles

Heracles is a modern, high-contrast dark-mode fitness tracking and analytics web application built with HTML, CSS, and JavaScript. It features customizable workout routines, a calendar-based navigation system, an active session stopwatch with lap tracking, yearly consistency heatmaps, and comprehensive exercise progression charts—all saved locally.
